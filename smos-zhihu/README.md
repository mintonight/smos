# SMOS · Zhihu

SMOS（Social Media Only Search）是一个减少信息流干扰的油猴脚本系列。

本仓库是 SMOS 的知乎版本：保留知乎顶栏和导航，隐藏发现内容，在页面中央提供搜索框。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey。
2. 使用下方链接安装脚本：

**GitHub Raw（推荐）**

https://raw.githubusercontent.com/mintonight/smos/main/smos-zhihu/smos-zhihu.user.js

**jsDelivr**

https://cdn.jsdelivr.net/gh/mintonight/smos/smos-zhihu/smos-zhihu.user.js

3. 打开 https://www.zhihu.com/ 或 https://www.zhihu.com/explore。

## 功能

- 支持知乎根首页和发现页。
- 保留知乎原生顶栏与导航。
- 隐藏推荐内容和发现内容。
- 在内容区显示中央搜索框。
- 搜索后进入知乎原生内容搜索结果页。
- 不处理问题详情页和搜索结果页。
