# SMOS · Xiaohongshu

SMOS（Social Media Only Search）是一个减少信息流干扰的油猴脚本系列。

本仓库是 SMOS 的小红书版本：保留小红书顶部搜索栏和左侧导航，隐藏发现内容，在页面中央提供搜索框。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey。
2. 使用下方链接安装脚本：

**GitHub Raw（推荐）**

https://raw.githubusercontent.com/mintonight/smos/main/smos-xiaohongshu/smos-xiaohongshu.user.js

**jsDelivr**

https://cdn.jsdelivr.net/gh/mintonight/smos/smos-xiaohongshu/smos-xiaohongshu.user.js

3. 打开 https://www.xiaohongshu.com/ 或 https://www.xiaohongshu.com/explore。

## 功能

- 支持小红书根首页和发现页。
- 保留顶部搜索栏、左侧导航、创作中心和通知入口。
- 隐藏发现页信息流和推荐内容。
- 在内容区显示中央搜索框。
- 搜索后进入小红书原生搜索结果页。
- 不处理笔记详情页和搜索结果页。
